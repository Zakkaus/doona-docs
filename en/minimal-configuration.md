# Minimal configuration

Choose the configuration for the interface you want. For other options, see [Configuration](https://doona.daeuniverse.org/en/configuration.md).

| Interface | Configuration |
| --- | --- |
| Standard edition embedded in honk | [Quick start, step 2](https://doona.daeuniverse.org/en/quick-start.md#2-configure-honk) |
| doona lite embedded in honk | [Install doona lite](https://doona.daeuniverse.org/en/lite.md#lite-install) |
| Separately installed UI files | [Install doona separately](https://doona.daeuniverse.org/en/install.md) |

These blocks enable the UI and native API, not proxy routing. Keep your existing honk configuration or prepare the backend as described in [Quick start](https://doona.daeuniverse.org/en/quick-start.md).
