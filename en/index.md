# doona documentation

doona is a web interface for managing honk and inspecting its traffic through the native API. These pages cover v0.1.0-rc.4.

<a name="choose-edition"></a>

## Choose an edition

| Edition | Use it for | Next step |
| --- | --- | --- |
| Standard | Configuration editing, traffic monitoring and routing diagnostics | [Quick start](https://doona.daeuniverse.org/en/quick-start.md) for embedded doona, or [install the separate package](https://doona.daeuniverse.org/en/install.md#doona); then [First sign-in](https://doona.daeuniverse.org/en/first-sign-in.md) |
| doona lite | Configuration tasks through a smaller interface; a preview in testing | [Install lite](https://doona.daeuniverse.org/en/lite.md#lite-install), then [Connect](https://doona.daeuniverse.org/en/lite-connect.md) |

See the [edition comparison](https://doona.daeuniverse.org/en/editions.md). To explore sample data, open the [standard demo](https://demo.daeuniverse.org/) or [lite demo](https://demo.daeuniverse.org/lite/).

## Start here

| Your starting point | Follow this page |
| --- | --- |
| New installation | [Quick start](https://doona.daeuniverse.org/en/quick-start.md): use honk’s embedded doona and sign in |
| honk is running and you want to use a proxy | [Route your first connection](https://doona.daeuniverse.org/en/tutorial.md): add a subscription, group, routing rule and DNS rule |
| You need separate UI files | [Install doona separately](https://doona.daeuniverse.org/en/install.md) |
| You have signed in and want to find a control | [Interface tour](https://doona.daeuniverse.org/en/tour.md) |

## Look up a requirement or solve a problem

- A page or action is unavailable: [Feature requirements](https://doona.daeuniverse.org/en/feature-requirements.md).
- You need a configuration key: [Configuration reference](https://doona.daeuniverse.org/en/configuration.md).
- You need a change's storage location or restart requirements: [What doona can change](https://doona.daeuniverse.org/en/what-doona-can-change.md).
- A connection, sign-in or write fails: [Troubleshooting](https://doona.daeuniverse.org/en/troubleshooting.md).
- You want to build or contribute: [Development](https://doona.daeuniverse.org/en/development.md).

Downloads are on [doona releases](https://github.com/Zakkaus/doona/releases). Report interface problems in [doona issues](https://github.com/Zakkaus/doona/issues).

Report engine problems to [honk issues](https://github.com/daeuniverse/honk/issues).
