# Documentation fonts

Source Sans 3 approximates Adobe Clean's letterforms. Source Code Pro matches the reference site's code face. The site serves the official Google Fonts Latin WOFF2 subsets locally, without further modification. Chinese text falls back to Noto Sans TC or SC, then the system sans-serif font.
