# doona 文件

doona 透過原生 API 管理 honk、查看流量。本文件適用於 v0.1.0-rc.4。

<a name="choose-edition"></a>

## 選擇版本

| 版本 | 用途 | 下一步 |
| --- | --- | --- |
| 標準版 | 編輯組態、觀測流量、診斷路由 | 依[快速入門](https://doona.daeuniverse.org/zh-TW/quick-start.md)使用內嵌的 doona，或[安裝獨立套件](https://doona.daeuniverse.org/zh-TW/install.md#doona)；然後[首次登入](https://doona.daeuniverse.org/zh-TW/first-sign-in.md) |
| doona lite | 用較精簡的介面完成組態任務，目前為測試中的預覽版 | [安裝 lite](https://doona.daeuniverse.org/zh-TW/lite.md#lite-install)，然後[連線至後端](https://doona.daeuniverse.org/zh-TW/lite-connect.md) |

版本差異見[版本比較](https://doona.daeuniverse.org/zh-TW/editions.md)。若要用範例資料體驗介面，開啟[標準版示範](https://demo.daeuniverse.org/)或 [lite 示範](https://demo.daeuniverse.org/lite/)。

## 從這裡開始

| 你目前的情況 | 閱讀頁面 |
| --- | --- |
| 首次安裝 | [快速入門](https://doona.daeuniverse.org/zh-TW/quick-start.md)：使用 honk 內嵌的 doona 並登入 |
| honk 已啟動，準備使用代理 | [路由你的第一條連線](https://doona.daeuniverse.org/zh-TW/tutorial.md)：新增訂閱、策略群組、路由規則和 DNS 規則 |
| 需要獨立介面檔案 | [單獨安裝 doona](https://doona.daeuniverse.org/zh-TW/install.md) |
| 已登入，想找到某項操作 | [介面導覽](https://doona.daeuniverse.org/zh-TW/tour.md) |

## 查找需求或排查問題

- 頁面或操作無法使用：[功能需求](https://doona.daeuniverse.org/zh-TW/feature-requirements.md)。
- 查找組態欄位：[組態參考](https://doona.daeuniverse.org/zh-TW/configuration.md)。
- 確認修改儲存在哪裡、是否需要重新啟動：[doona 能修改什麼](https://doona.daeuniverse.org/zh-TW/what-doona-can-change.md)。
- 連線、登入或寫入失敗：[疑難排解](https://doona.daeuniverse.org/zh-TW/troubleshooting.md)。
- 建置或參與開發：[開發](https://doona.daeuniverse.org/zh-TW/development.md)。

下載見 [doona 發布頁面](https://github.com/Zakkaus/doona/releases)。介面問題請提交至 [doona issues](https://github.com/Zakkaus/doona/issues)。

引擎問題請提交至 [honk issues](https://github.com/daeuniverse/honk/issues)。
