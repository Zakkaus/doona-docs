# doona 文档

doona 通过原生 API 管理 honk、查看流量。本文档适用于 v0.1.0-rc.4。

<a name="choose-edition"></a>

## 选择版本

| 版本 | 用途 | 下一步 |
| --- | --- | --- |
| 标准版 | 编辑配置、观测流量、诊断路由 | 按[快速入门](https://doona.daeuniverse.org/zh-CN/quick-start.md)使用内嵌的 doona，或[安装独立软件包](https://doona.daeuniverse.org/zh-CN/install.md#doona)；然后[首次登录](https://doona.daeuniverse.org/zh-CN/first-sign-in.md) |
| doona lite | 用较精简的界面完成配置任务，目前为测试中的预览版 | [安装 lite](https://doona.daeuniverse.org/zh-CN/lite.md#lite-install)，然后[连接后端](https://doona.daeuniverse.org/zh-CN/lite-connect.md) |

版本差异见[版本比较](https://doona.daeuniverse.org/zh-CN/editions.md)。若要用示例数据体验界面，打开[标准版演示](https://demo.daeuniverse.org/)或 [lite 演示](https://demo.daeuniverse.org/lite/)。

## 从这里开始

| 你目前的情况 | 阅读页面 |
| --- | --- |
| 首次安装 | [快速入门](https://doona.daeuniverse.org/zh-CN/quick-start.md)：使用 honk 内嵌的 doona 并登录 |
| honk 已启动，准备使用代理 | [路由你的第一条连接](https://doona.daeuniverse.org/zh-CN/tutorial.md)：添加订阅、策略组、路由规则和 DNS 规则 |
| 需要独立界面文件 | [单独安装 doona](https://doona.daeuniverse.org/zh-CN/install.md) |
| 已登录，想找到某项操作 | [界面导览](https://doona.daeuniverse.org/zh-CN/tour.md) |

## 查找要求或排查问题

- 页面或操作不可用：[功能要求](https://doona.daeuniverse.org/zh-CN/feature-requirements.md)。
- 查找配置项：[配置参考](https://doona.daeuniverse.org/zh-CN/configuration.md)。
- 确认修改保存在哪里、是否需要重启：[doona 能修改什么](https://doona.daeuniverse.org/zh-CN/what-doona-can-change.md)。
- 连接、登录或写入失败：[故障排查](https://doona.daeuniverse.org/zh-CN/troubleshooting.md)。
- 构建或参与开发：[开发](https://doona.daeuniverse.org/zh-CN/development.md)。

下载见 [doona 发布页面](https://github.com/Zakkaus/doona/releases)。界面问题请提交到 [doona issues](https://github.com/Zakkaus/doona/issues)。

引擎问题请提交到 [honk issues](https://github.com/daeuniverse/honk/issues)。
