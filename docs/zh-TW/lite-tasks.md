# doona lite 常見操作

使用 doona lite 匯入資源並編輯 honk 組態。請先[連線後端](lite-connect.md)；編輯需要啟用 `config_write`，且主組態可寫入。也可選擇**試用示範**練習，重新載入頁面後修改會重設。

<a name="lite-task-import"></a>

## 從分享連結匯入節點

1. 開啟**節點**，選擇**匯入**。
2. 在**分享連結**中每行貼上一個連結，然後選擇**檢查連結**。
3. 檢查解析出的節點，然後選擇**儲存節點**。匯入的節點會出現在清單中。

<a name="lite-task-subscription"></a>

## 新增訂閱

1. 開啟**訂閱**，選擇**新增訂閱**。
2. 輸入**名稱**與**訂閱 URL**。
3. 選擇**儲存**。訂閱會出現在清單中。

<a name="lite-task-group"></a>

## 建立群組並選擇成員

1. 開啟**策略群組**，選擇**建立群組**。
2. 輸入**名稱**，選擇**策略**，例如**手動選擇**，然後選擇**建立**。
3. 在**編輯群組**中，從**可用節點與訂閱**找到節點，選擇其**加入**按鈕。節點會出現在**已加入**中。
4. 選擇**檢視並套用**，檢查群組與成員，然後選擇**套用**。

<a name="lite-task-rule"></a>

## 新增路由規則

1. 開啟**路由**，選擇**新增規則**。
2. 要比對網域，保留**網域及子網域**，在**值**中輸入 `example.com`，按 Enter。
3. 在**走向**中選擇群組，並選擇**位置**，然後選擇**新增**。
4. 選擇**檢視並套用**，檢查規則，然後選擇**套用**。

**用範本重建規則**對話框可替換草稿中的路由規則。儲存前請檢查替換清單；此操作並非僅附加一條規則。

<a name="lite-task-dns"></a>

## 修改 DNS 上游

1. 開啟 **DNS**，選擇**新增 DNS 伺服器**。
2. 在**服務商**中保留**自訂**。輸入唯一的**名稱**與**伺服器位址**，例如 `tls://1.1.1.1:853`，然後選擇**新增**。
3. 開啟該伺服器的**操作**選單，選擇**設為預設**，讓其他網域使用該伺服器。
4. 選擇**檢視並套用**，檢查伺服器與規則的修改，然後選擇**套用**。

<a name="lite-task-setting"></a>

## 修改全域設定

1. 開啟**設定**，選擇**流量辨識**。
2. 將**嗅探逾時**設為 `200`，將其**時間單位**設為 `ms`。
3. 選擇**檢視變更**，檢查修改，然後選擇**套用**。

需要重新啟動的設定在此處停用。請在後端修改，再重新啟動 honk。

<a name="lite-task-share"></a>

## 透過連結或 QR code 分享節點

1. 開啟**節點**，找到手動新增的節點。
2. 開啟節點的**操作**選單，選擇**分享**，開啟連結與 QR code。
3. 選擇**複製連結**，或掃描 QR code。如果無法複製，請選取並複製顯示的連結。

訂閱節點不提供分享連結。連結過長時可能不顯示 QR code，請改為複製連結。分享連結包含連線憑證。
