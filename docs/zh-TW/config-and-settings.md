# 組態與設定

「組態」頁讀取、驗證並套用 honk 的設定檔。「設定」頁管理連線設定檔、暫時執行時期覆寫、地理資料、外觀與延遲探測。「活動」的[開始使用](observe.md#activity)卡片連結到設定步驟。

<a name="config-page"></a>

## 開啟「組態」頁

1. 在「設定」分區中開啟「組態」。後端提供組態內容或備份與修訂功能時顯示此頁面。
2. 查看分頁上方的一行資訊。「組態版本」標示目前生效的組態，內容變更並生效後會改變。旁邊的狀態顯示「沒有診斷」，或錯誤與警告的數量。
3. 若該行另外顯示「後端已遮蔽監聽密鑰的值」，表示後端在回傳的文字中隱藏了這些值。
4. 選擇「模組」或「設定檔」。doona 支援該引擎的設定時顯示「全域設定」；後端提供組態匯出、匯入或修訂歷史時顯示「備份與修訂」。

連結未指定分頁時，頁面預設開啟「模組」，主組態為空時也如此。連結指定了來源，或後端未回傳主組態文字時，預設開啟「設定檔」。設定檔格式以及主組態與 `include` 檔的作用，見[組態說明](configuration.md#config)。

新增訂閱請開啟「節點」並點選「新增訂閱」，見[節點與訂閱](routing.md#nodes)。套用規則範本請開啟「規則」，見[路由規則](routing.md#rules)。

### 設定檔

1. 開啟「設定檔」，從「設定檔」下拉選單選擇檔案。每一項都標示檔案類型：「主組態」「引入檔」「訂閱」或「引擎產生」。
2. 下拉選單旁顯示檔案的行數與大小。將指標停在上面可查看載入時間。
3. 檔案不可編輯時，下拉選單旁會顯示標記，說明原因。各標記的含義見下表。
4. 點選「下載來源檔案」可下載顯示的文字。匯出檔案保留顯示的原始文字，可能含有憑證，分享前須檢查。

| 標記 | 含義 |
| --- | --- |
| 「唯讀」 | 後端未開放寫入組態；標記旁的說明提供啟用方式，[組態說明](configuration.md#config)介紹 `config_write`。若沒有該說明，表示後端拒絕寫入此檔案且未提供原因，見[唯讀組態檔案](troubleshooting.md#read-only)。 |
| 「含密鑰」 | 檔案含監聽密鑰，後端不會寫回。將密鑰移到獨立的引入檔後，即可編輯其餘內容。 |
| 「內容已遮蔽」 | 後端隱藏了檔案的部分內容，寫回會遺失這些值。 |
| 「訂閱」 | 檔案從訂閱網址下載，更新訂閱時會被取代。 |
| 「引擎產生」 | 檔案由引擎產生，重新產生時會被覆寫。如需變更，請修改產生它的組態。 |

在唯讀檔案中輸入內容時，頁面會提示一次「此檔案唯讀」。

<a name="edit-source"></a>

## 編輯並套用來源

1. 在「設定檔」中選擇可寫且文字完整的檔案，點選其文字。
2. 輸入修改。頁面顯示「未套用」標記；此時重新載入或關閉頁面會遺失修改。
3. 若後端支援驗證，doona 會在停止輸入片刻後檢查主組態及其引入檔。點選「驗證」可立即檢查。
4. 檢查[草稿診斷](#驗證與診斷)，再點選「套用」。honk 驗證檔案、寫入修改並重載組態；提示訊息確認寫入與重載結果。

點選「取消」可放棄修改。驗證發現錯誤時不會寫入任何內容，錯誤顯示在清單中。若修改涉及需重新啟動才生效的設定，同樣不會寫入。提示列出這些設定與重新啟動命令；請在磁碟上修改，再[重新啟動 honk](service-management.md)。

若編輯期間磁碟上的檔案已變更，頁面會顯示提示，「套用」無法使用。點選「保留修改」後再點選「套用」，可用你的文字覆寫新檔案；點選「取消」則放棄修改並載入新文字。

新增引入檔：

1. 在「設定檔」中點選「新增檔案」。後端允許建立可寫檔案時才顯示此按鈕。
2. 若主組態的 include 路徑樣式已決定目錄與副檔名，只需在「名稱」中輸入檔名；有多個路徑樣式時，先在「路徑樣式」中選擇。否則在「路徑」中輸入相對於主組態目錄的路徑，路徑須以 `.dae` 結尾。
3. 點選「建立」。新檔案內容為空，組態隨即重新載入，並在「設定檔」中開啟該檔案。

若已載入檔案的 include 路徑樣式都不符合該路徑，對話框會提示後端將拒絕建立。

「新增檔案」結果無法確認時顯示資訊提示，而非錯誤。「全域設定」中常規的唯讀提示也使用資訊等級。

## 驗證與診斷

![編輯器工具列下方的「目前草稿的診斷」：帶數量的等級篩選、「前往」按鈕與行標記](../screenshots/zh-TW/config-diagnostics.webp)

這些診斷屬於尚未套用的草稿，而不是已接受的組態。所選等級沒有項目時，篩選回到「全部」；「開啟」跳至其他檔案。

草稿尚未驗證時，清單顯示生效組態的診斷。驗證需要主組態與引入檔的完整文字。套用修改或接受新 `generation` 後，先前的驗證結果會清除。原「驗證」分頁的連結會開啟「設定檔」中的診斷。

## 模組

1. 開啟「模組」。每個 `global`、`subscription`、`node`、`group`、`dns` 與 `routing` 區段各顯示一張卡片，列出行範圍與一行摘要。
2. 點選「開啟頁面」，可開啟該區段的編輯頁面：「全域設定」「節點」「策略」，或「規則」頁的 DNS 清單與路由清單。

「模組」只提供概覽，不提供內嵌編輯器。編輯完整檔案請使用「設定檔」。缺少的區段會顯示提示。

## 全域設定

1. 開啟「全域設定」，從「設定檔」選擇區段。清單包含主組態與引入檔中的 `global` 區段；主組態尚無該區段時可新增。
2. 修改介面、撥號與 TLS、節點檢查、日誌、儲存、頻寬與預先連線等欄位。每項顯示組態鍵及單位或範圍。「未設定」使用引擎預設值；重複欄位須在「設定檔」中處理。透明代理與效能分析連接埠使用附減少與增加按鈕的數字欄位；連接埠顯示為 `8080`，不加千位分隔符，清空後設為未設定。輸入低於欄位最小值的數字時，所輸入內容會保留到輸入完成；整數欄位不接受小數點。
3. 點選「寫入並重新載入」，驗證、寫入並套用修改。「放棄修改」捨棄草稿。

只有可寫且文字完整的檔案能修改。磁碟檔案已變更時不能儲存。需重新啟動才生效的修改會遭拒絕，且不會寫入；提示列出須在磁碟上修改的設定。寫入成功但無法讀取新組態時，草稿保留並提供「重試」。

honk 的儲存訂閱內容（`global.store_subscribe`）將成功取得並通過檢查的訂閱內容儲存到 `<data_dir>/state/honk.db` 的 `subscription_body` 表，預設路徑為 `/var/lib/honk/state/honk.db`。變更這項設定須重新啟動 honk；訂閱的 `cache: false` 會停用其內容儲存與還原。獨立的 `.sub` 檔案屬於舊版儲存格式，啟動時的遷移規則見[固定版本的 honk 參考文件](https://github.com/Glassyiris/honk/blob/6ad0ab89bfdf2a72d3e08b00714bb8434ffdc1df/doc/en/reference/subscription.md#fetch-persistence-and-recovery)。

## 備份與修訂

![Export、Import 與 revision Restore 使用不同組態來源](../images/config-recovery.svg)

Export 下載已接受的來源檔案；Import 讀取 honk 啟動時 `-c` 指定的伺服器檔案樹，不上傳本機檔案，Restore 使用修訂快照。Import 與 Restore 經確認後驗證並套用；覆寫目前組態前，可開啟修訂列檢查中繼資料與來源檔案 SHA-256。

與「匯出組態」不同，「下載來源檔案」只下載顯示的檔案。匯出不含監聽密鑰，但可能保留其他憑證，分享前須檢查。

已接受的匯入或復原操作結果未知時，重新開啟此分頁，點選「重新整理」查詢原操作，不會再次寫入。資料庫 head 已變更時須檢查並重新確認。

<a name="settings-page"></a>

## 「設定」頁

在「設定」分區中開啟「設定」。未連線後端時也能開啟此頁面，因此可以在此修正後端網址。頁面有「一般」與「外觀」兩個分頁，預設開啟「一般」，卡片依下列順序排列：

1. 「後端」
2. 「暫時執行期覆寫」
3. 「地理資料」，後端提供地理資料時顯示
4. 「延遲探測」
5. 「關於」

「外觀」分頁包含下文的「外觀」卡片。`#/settings?tab=appearance` 可直接開啟此分頁；外觀設定的連結與搜尋結果也會開啟它。

![一般設定及一般、外觀兩個分頁](../screenshots/zh-TW/settings-general.webp)

![外觀設定中的四種玻璃配色](../screenshots/zh-TW/settings-appearance.webp)

### 後端

1. 在「連線設定檔」中選擇設定檔即可切換。doona 儲存選擇後重新載入頁面，連線至該後端。
2. 使用「新增連線設定檔」「重新命名連線設定檔」或「刪除連線設定檔」管理連線設定檔。每項操作都會開啟對話框，確認後頁面重新載入。新增的連線設定檔預設使用內建示範資料。
3. 填寫「後端網址」：後端的根網址或反向代理前綴，不是 `/api/v1`。留空或填入 `mock` 可使用內建示範資料。
4. 填寫「Token」。使用密碼登入的後端會顯示說明而非此欄位；登入後會顯示「登出」。
5. 點選「測試連線」。結果顯示「連線成功，API v*N*」，或說明失敗原因。
6. 點選「儲存」。doona 將連線設定檔儲存在此瀏覽器中，並重新載入頁面以套用該設定檔。

切換、新增、重新命名或刪除連線設定檔都會放棄尚未儲存的「後端網址」與「Token」修改；對話框會事先提示。配對連結會填入「後端網址」與「Token」，儲存後生效。「儲存」修改的是 doona 的連線設定檔，不是 honk 的組態。測試連線或登入失敗時，見[登入失敗](troubleshooting.md#sign-in)。

目前連線設定檔使用已儲存的 Token 時也顯示「登出」。此操作移除此瀏覽器中的 Token、保留後端位址並返回登入頁，不撤銷後端金鑰。密碼登入的登出操作會關閉工作階段，並移除已儲存的 Token。

<a name="runtime-options"></a>

### 暫時執行期覆寫

1. 查看標題旁的標記：「組態值」或「執行期覆寫」。
2. 修改後端提供的欄位：「日誌等級」「日誌保留筆數」「DNS 記錄保留筆數」「流程保留筆數」與「流程保留秒數」。每個數值欄位都顯示允許的範圍。
3. 「流程記錄」可選擇「依流程需求」「常開」或「關閉」。「日誌記錄」可選擇「依日誌需求」「常開」或「關閉」。「DNS 記錄」可選擇「依 DNS 日誌需求」「常開」或「關閉」。每項旁的狀態顯示「記錄中」「未記錄」或「組態禁止」。
4. 點選「套用」，修改立即生效。有未套用的修改時會顯示「放棄修改」。

這些選項不會寫入組態檔。重新啟動或已接受的明確組態啟用（包括沒有內容變更的重新載入）會恢復組態檔中的值。啟用被拒絕、訂閱或網路重新整理時，覆寫值保持不變。組態中禁止的記錄功能不能在此啟用。若編輯期間後端選項已變更，doona 會保留草稿並提示。

「在組態中編輯持久設定」開啟「全域設定」，用於修改寫入 honk 組態的值。

<a name="geodata"></a>

### 地理資料

![「地理資料」卡片，顯示「立即更新」「重設為預設值」，並展開「詳細資料」，顯示檢查時間與檔案下載資訊，下方為檔案表](../screenshots/zh-TW/settings-geodata.webp)

「重設為預設值」需要確認，之後刪除所有覆寫值與取自設定檔的值。即使來源無法設定，也會顯示檔案表。

「詳細資料」列出「上次檢查」與「下次檢查」，以及每個檔案的大小、下載主機與路由。下方的檔案表顯示各檔案的更新時間。

1. 選擇「來源」：「Loyalsoldier」「MetaCubeX 完整版」「MetaCubeX 精簡版」或「自訂」。若預設缺少規則使用的分類，切換前會開啟對話框列出這些分類，因為後端更新時會拒絕這類檔案。
2. 選擇「自訂」時，在「自訂網址」對話框中填寫 `geosite` 與 `geoip` 的網址，然後點選「套用並更新」或「套用」。每種資料最多 4 個網址，依序嘗試。請填寫直接回傳檔案的網址；GitHub Releases 下載連結會重新導向，無法使用。之後可點選「編輯」重新開啟對話框。
3. 選擇「下載路由」：「依路由規則」「直連」或「指定群組」。選擇「指定群組」後還須選擇群組，選定後路由才會儲存。
4. 除非可信鏡像站的校驗位址回傳錯誤頁面或 HTTP 404 以外的錯誤，否則保持開啟「SHA-256 驗證」。鏡像站未提供 `.sha256sum` 檔案時，檔案本來就會不經驗證直接載入。
5. 開啟「自動更新」並選擇「更新間隔（小時）」，即可定時下載。

每個控制項修改後立即儲存。後端支援手動更新時，更換來源後隨即下載新檔案；否則在下次自動更新時下載。只有後端提供相應資訊時，才顯示「下載路由」與「SHA-256 驗證」。若卡片提示網址來自組態檔，honk 重新啟動時會再次寫入這些網址。更新失敗時，見[地理資料更新失敗](troubleshooting.md#geodata-update)與[地理資料來源](troubleshooting.md#geodata-sources)。

### 外觀

可選擇「語言」「配色」「明暗模式」「字標」與「通知位置」。開啟「鏡像版面」可將版面左右翻轉。doona 將這些選項儲存在此瀏覽器中，不會修改 honk 的組態。

「日期格式」預設為「自動（瀏覽器地區）」；「日/月/年」「月/日/年」與「年-月-日」可覆寫日期順序。「時間格式」預設為「24 小時制」；「12 小時制」使用介面語言的上午、下午文字，「自動（瀏覽器地區）」依瀏覽器地區的慣例顯示。兩者適用於各頁，包括圖表座標軸與日誌熱圖，並儲存在目前瀏覽器中。

「配色」把每種配色顯示為一個方框，方框內的小視窗以其亮色與暗色繪製。「玻璃」分區提供「液態玻璃」「玻璃」「毛玻璃」與「著色」。「液態玻璃」僅在 Chromium 核心的瀏覽器中產生折射；Firefox 與 Safari 將其繪製為「玻璃」，只有模糊與填色效果。「毛玻璃」對所有表面使用同一程度的模糊；「著色」的表面近乎不透明，不產生模糊。 「液態玻璃」的事件與日誌表格保留模糊、透明與色彩效果，但不產生折射與明亮邊緣。

系統設為降低透明度、提高對比度或強制色彩模式時，這些配色顯示為不透明表面，邊緣清晰。

先前透過設定中的開關選擇的玻璃材質，會沿用為對應的配色。

選擇玻璃配色後，「背景圖片 > 選擇圖片」可替換頁面與登入頁後方的背景圖片；「使用預設」恢復內建圖片。圖片長邊縮放至最多 2560 像素，僅儲存在此瀏覽器的 IndexedDB 中。瀏覽器無法儲存時，僅在本次工作階段中保留。

選擇圖片後，「可讀性遮罩」在亮色模式疊加白色，在暗色模式疊加黑色。遮罩預設開啟，「淡化」調整其強度，最高 60%，預設也是 60%。關閉遮罩後，顯示原圖。

「模糊程度」可在 0% 至 150% 之間調整「液態玻璃」「玻璃」與「毛玻璃」各表面的模糊，無論是否使用自訂圖片；低於 100% 時，表面填色會加深，使文字保持可讀。「著色」不使用模糊，也不顯示此控制項。

「顯示國旗」控制節點名稱前的國旗，不影響路由。「活動卡片顯示趨勢圖」控制「活動」頁流量、CPU 與延遲卡片的近期數值趨勢圖。

「啟動時開啟」選擇位址未指定頁面路由時開啟的頁面，預設為「活動」，修改後立即儲存在此瀏覽器中。指定頁面的連結仍開啟原目標。未設定後端時，未指定頁面路由的位址仍開啟「設定」。

<a name="backend-actions"></a>

### 後端控制

後端操作位於各自的頁面：

1. 「系統狀態」的狀態列旁提供操作按鈕。「重載」重新讀取 honk 組態；後端支援時才顯示「暫停」或「恢復」。
2. 「DNS」提供快取刪除與「清除全部快取」。快取列提供刪除圖示；快取與「解析記錄」的各列提供新增規則圖示，用於在「規則」的「DNS 規則」中新增「request 規則」。DNS 規則無法使用時，改為新增路由規則。
3. 「節點」提供「更新 N 個訂閱」。
4. 「連線」提供「全部關閉」，關閉後端持有的連線並跳過核心直連連線。

頂端列的「重載 honk」經確認後執行重載，不會寫入暫存規則，見[介面導覽](tour.md#top-bar)與[暫存規則](routing.md#held-rules)。

### 延遲探測

選擇「探測方式」「IP 版本」「連線」與「策略群組探測」。「連線」可選「暖探測（重用連線）」或「冷探測（新連線）」；「策略群組探測」可選「直接成員」或「含巢狀群組的所有節點」。這些選擇儲存在此瀏覽器中，探測按鈕使用這些設定，選項對話框也以此為初始值。節點無法使用所選方式時，會採用其支援的方式並說明替代結果。

Trojan、AnyTLS 與 VLESS 保留依賴節點組態的 DNS UDP 選項；後端拒絕執行時會顯示原因，不會靜默改用 HTTP。探測未完成測量時可能顯示「結果不明」，並說明逾時、取消、缺少可用位址或本機拒絕的原因。這不代表節點無法使用。

「在組態中編輯健康檢查」開啟持久的背景檢查設定，包括檢查 URL 與間隔。這些設定與手動探測選項相互獨立。

### 關於

「關於 doona」會開啟對話框，顯示引擎、API 與契約版本、授權和隱私說明。「鍵盤快捷鍵」會開啟快捷鍵清單。「指南」會以介面語言開啟本文件。瀏覽器提供安裝功能時顯示「安裝為應用程式」；iOS 與 macOS 上的 Safari 則顯示安裝步驟。若後端的 API 主版本不是 1，此卡片會顯示警告。

「複製最近錯誤」複製記憶體中保留的最近 20 筆 API 錯誤，供問題報告使用，不含密鑰與請求主體。重新載入頁面會清除記錄。失敗提示也提供「複製錯誤」，用於複製單次請求的錯誤資訊。

讀取回應為空或沒有回應時，會重試一次再顯示錯誤。錯誤詳細資料列出失敗的請求與主要回應標頭。
