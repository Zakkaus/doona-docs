# 介面導覽

本頁說明登入 doona 後各項功能的位置：四個導覽分區、頂端列，以及頁面內的分頁、詳細資料面板與操作選單。本頁也說明暫存、套用與儲存的差別，如何確認變更已生效，以及手機上的版面變化。

<a name="navigation"></a>

## 尋找頁面

視窗寬度至少 1024 px 時，側邊欄依四個分區列出頁面。點選頁面名稱即可開啟該頁面。

### 「活動」

- 「活動」：出站模式、下載與上傳速率、使用中的連線、目前節點、CPU、流量、出站用量、流量最多的裝置與網域、記憶體以及通知。
- 「系統狀態」：引擎狀態、流量計數、記憶體、資料路徑掛載點與後端能力，並提供「匯出狀態 JSON」。

### 「觀測」

- 「連線」：包含「流量」與「連線」分頁。選取一條連線可查看其路由與可用操作。
- 「分流」：包含「總覽」與「記錄」分頁。
- 「DNS」：包含「統計」「解析記錄」「快取」與「查詢」分頁，實際顯示哪些分頁取決於後端提供的功能。
- 「日誌」：引擎即時日誌，可依「等級」與「模組」篩選，並提供「暫停」「清空」與「匯出」。
- 「事件」：後端狀態變更記錄，並提供「匯出 JSON」。

### 「路由」

- 「策略」：包含「群組」與「群組成員」分頁。可為群組選擇節點或調整群組成員。
- 「節點」：節點及其訂閱、用量與重新整理。後端提供節點清單時會顯示「延遲」分頁。
- 「規則」：包含「路由規則」「DNS 規則」與「追蹤模擬」分頁；只有後端提供 DNS 規則時才顯示「DNS 規則」分頁。

### 「設定」

- 「組態」：包含「模組」「快速設定」「來源」與「驗證」分頁；只有可用時才顯示「快速設定」。
- 「設定」：包含「後端」「後端選項」「地理資料」「外觀」「後端操作」與「關於」卡片。

後端不提供某個頁面時，該頁面仍保留在導覽中。開啟後會顯示「此後端不提供該頁面」與「回到活動」按鈕；詳見[功能所需條件](features.md#still-missing)。

按 `?` 開啟「鍵盤快捷鍵」。先按 `g`，再於 800 毫秒內按下頁面字母，即可開啟對應頁面，例如 `g` `r` 開啟「規則」。

<a name="top-bar"></a>

## 使用頂端列

1. 點選側邊欄底部的後端指示器。彈出框會顯示引擎及版本、連線狀態（例如「已連線」或「需要登入」）、API、「後端網址」與「設定檔」。點選「編輯後端」可開啟「設定」頁的「後端」卡片，點選「關於 doona」可查看版本資訊。
2. 點選搜尋框，或按 `Ctrl K`（macOS 上按 `⌘K`）。輸入頁面、分頁、節點、群組或節點來源名稱的一部分，也可以輸入目前的連線、組態檔案路徑或規則運算式。點選搜尋結果即可開啟。
3. 有暫存規則時，頂端列會出現帶有勾選圖示與暫存規則數量的按鈕。按鈕名稱為「套用（N）」；規則寫入多個檔案時為「套用（N），將寫入 F 個檔案」。點選後會寫入全部暫存規則；詳見[暫存清單](routing.md#held-rules)。
4. 點選「重載 honk」，並在「重載 honk？」對話框中確認。honk 會重新讀取組態檔案並重載，暫存的規則不會寫入。只有後端支援重載時才顯示此按鈕。
5. 點選「重新整理」或按 `r`，從後端重新讀取頁面上的全部資料。完成後顯示提示訊息「資料已重新整理。」。重新整理不寫入任何內容，也不重載 honk。
6. 點選主題按鈕切換亮色與暗色。主題跟隨系統時，點選後切換為相反的配色方案；再次點選則恢復為「跟隨系統」。旁邊是「語言」與「配色」選單；「字標」選項位於「配色」選單中。

「套用（N）」與「重載 honk」不會同時執行：其中一個執行時，另一個無法使用。

<a name="panels"></a>

## 使用分頁、詳細資料與操作

1. 點選頁面標題下方的分頁，切換頁面內的檢視。切換分頁不會切換頁面。
2. 在「連線」「分流」或「DNS」中選取一列，開啟詳細資料。視窗寬度至少 1200 px 時，詳細資料顯示在清單旁的面板中；視窗較窄時以抽屜顯示。
3. 使用面板中唯一的主要按鈕執行主要工作。連線詳細資料的主要按鈕是「新增規則」。
4. 點選「更多操作」（直排三點按鈕）查看其他命令。連線詳細資料中包括「檢視命中的規則」「檢視流程」「追蹤此連線」與「關閉連線」；破壞性操作排在最後。
5. 點選「關閉」或按 `Esc` 關閉面板。

<a name="commit-verbs"></a>

## 暫存、套用或儲存

- 「暫存」只出現在從觀測流量開啟的「新增規則」對話框中，例如從連線或 DNS 記錄開啟，且是其中醒目顯示的按鈕。「暫存」將規則加入暫存清單，但不寫入；之後可透過頂端列的「套用（N）」或「規則」頁的「套用暫存的規則」寫入，詳見[暫存清單](routing.md#held-rules)。「規則」頁開啟的「新增規則」對話框會直接寫入；詳見[新增規則](routing.md#add-rule)。
- 「套用」立即將變更寫入後端。在從觀測流量開啟的「新增規則」對話框中，「套用」會立即寫入這條規則並重載 honk。「組態」頁以「套用」寫入編輯後的來源；「設定」頁的「後端選項」卡片以「套用」提交執行期變更，這些變更不寫入組態檔案。詳見[編輯來源](config-and-settings.md#edit-source)與[後端選項](config-and-settings.md#runtime-options)。
- 「儲存」將設定檔存放在目前的瀏覽器中。儲存後頁面會重新載入以套用該設定檔；詳見[設定](config-and-settings.md#settings-page)。

<a name="confirm"></a>

## 確認變更已生效

1. 查看寫入後的提示訊息。寫入規則後會顯示「新規則已生效」「規則變更已生效」，或在使用「套用（N）」後顯示「N 條規則已生效」。
2. 查看提示訊息中的說明：「現有連線維持目前的路由，重新連線後才套用變更。」
3. 如需檢查新路由，開啟「連線」，查看變更後新建立的連線。

寫入失敗時，提示訊息會顯示原因，未寫入的暫存規則仍保留在暫存清單中。組態檔案為唯讀時，請參閱[疑難排解](troubleshooting.md#read-only)。

<a name="phone"></a>

## 在手機上導覽

視窗寬度小於 1024 px 時，側邊欄由底部導覽列與頁面導覽列取代。

1. 在底部導覽列中選擇「活動」「觀測」「路由」或「設定」。每個分區會開啟本次瀏覽器工作階段中在該分區最近造訪的頁面；尚未造訪時開啟該分區的第一個頁面。
2. 在內容上方的頁面導覽列中選擇頁面。頁面無法全部顯示時，水平滑動導覽列；目前頁面會保持可見。
3. 點選頂端列的「更多選項」（直排三點按鈕），可使用「語言」「主題」「配色」與「字標」選單，以及「重載 honk」與「後端」。「後端」會開啟與側邊欄後端指示器相同的彈出框。
4. 搜尋按鈕、「重新整理」與「套用（N）」仍直接顯示在頂端列中，不收入選單。
5. 在頁面工具列中，第一個操作保留為按鈕，其餘操作收入「更多操作」。

安裝 honk 與 doona 請參閱[安裝指南](install.md)；組態檔案請參閱[組態](configuration.md#config)。
