# 連線 doona lite

將 doona lite 連線至 honk 原生 API，或在沒有後端時開啟示範。

1. 開啟 honk 的 `/ui/` 位址，或單獨託管的 lite 頁面。首次使用時，在**後端網址**中輸入伺服器根位址，例如 `http://192.168.1.1:9527`，不要附加 `/api/v1`。若頁面來自其他來源，請在 honk 上設定[來源存取權限](install.md#other-origin)。
2. 選擇**繼續**，檢查連線並取得登入方式。
3. 若顯示**設定管理員**，輸入**使用者名稱**、**密碼**與**確認密碼**，然後選擇**建立並登入**。只有當 honk 識別的用戶端位址屬於 loopback、私有或鏈路本地位址時，才允許建立管理員。帳戶要求與設定疑難排解見[首次登入](first-sign-in.md)。
4. 若顯示**登入**，輸入既有管理員的**使用者名稱**與**密碼**，然後選擇**登入**。
5. 在權杖模式下，將組態中的 `secret` 輸入**權杖**，然後選擇**連線至後端**。兩個版本使用相同的 honk 憑證。

無需後端即可選擇**試用示範**。示範中的修改僅儲存於記憶體，重新載入頁面後即重設。
