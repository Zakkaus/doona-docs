# 界面导览

本页说明登录 doona 后各项功能的位置：四个导航分区、顶部栏，以及页面内的分页、详情面板与操作菜单。本页还说明暂存、应用与保存的区别，如何确认修改已生效，以及手机上的布局变化。

<a name="navigation"></a>

## 查找页面

窗口宽度不小于 1024 px 时，侧边栏按四个分区列出页面。点击页面名称即可打开该页面。

### 「活动」

- 「活动」：出站模式、下载与上传速率、活动连接、当前节点、CPU、流量、出站用量、流量最多的设备与域名、内存以及通知。
- 「系统状态」：引擎状态、流量计数、内存、数据路径挂载点与后端能力，并提供「导出状态 JSON」。

### 「观测」

- 「连接」：包含「流量」和「连接」分页。选中一条连接可查看其路由与可用操作。
- 「分流」：包含「总览」和「记录」分页。
- 「DNS」：包含「统计」「解析记录」「缓存」和「查询」分页，具体取决于后端提供的功能。
- 「日志」：引擎实时日志，可按级别和目标筛选，并提供「暂停」「清空」和「导出」。
- 「事件」：后端状态变更记录，并提供「导出 JSON」。

### 「路由」

- 「策略」：包含「组」和「组成员」分页。可为组选择节点或调整组成员。
- 「节点」：节点及其订阅、用量与刷新。测得延迟后会出现「延迟」分页。
- 「规则」：包含「路由规则」「DNS 规则」和「追踪模拟」分页；只有后端提供 DNS 规则时才显示「DNS 规则」分页。

### 「设置」

- 「配置」：包含「模块」「快速设置」「来源」和「校验」分页；只有可用时才显示「快速设置」。
- 「设置」：包含「后端」「后端选项」「地理数据」「外观」「后端操作」和「关于」卡片。

后端不提供某个页面时，该页面仍保留在导航中。打开后会显示「此后端不提供该页面」和「回到活动」按钮；详见[功能所需条件](features.md#still-missing)。

按 `?` 打开「键盘快捷键」。先按 `g`，再于 800 毫秒内按下页面字母，即可打开对应页面，例如 `g` `r` 打开「规则」。

<a name="top-bar"></a>

## 使用顶部栏

1. 点击侧边栏底部的后端指示器。弹出框会显示引擎及版本、连接状态（例如「已连接」或「需要登录」）、API、「后端网址」和「连接方案」。点击「编辑后端」可打开「设置」页的「后端」卡片，点击「关于 doona」可查看版本信息。
2. 点击搜索框，或按 `Ctrl K`（macOS 上按 `⌘K`）。输入页面、分页、节点、组或节点来源名称的一部分，也可以输入当前连接、配置文件路径或规则表达式。点击搜索结果即可打开。
3. 存在暂存规则时，顶部栏会出现带勾选图标和暂存规则数量的按钮。按钮名称为「应用（N）」；规则写入多个文件时为「应用（N），将写入 F 个文件」。点击后会写入全部暂存规则；详见[暂存列表](routing.md#held-rules)。
4. 点击「重载 honk」，并在「重载 honk？」对话框中确认。honk 会重新读取配置文件并重载，暂存的规则不会写入。只有后端支持重载时才显示此按钮。
5. 点击「刷新」或按 `r`，从后端重新读取页面上的全部数据。完成后显示提示消息「数据已刷新。」。刷新不写入任何内容，也不重载 honk。
6. 点击主题按钮切换浅色与深色。主题跟随系统时，点击后切换为相反的配色方案；再次点击恢复为「跟随系统」。旁边是「语言」和「配色」菜单；「字标」选项位于「配色」菜单中。

「应用（N）」和「重载 honk」不会同时执行：其中一个执行时，另一个不可用。

<a name="panels"></a>

## 使用分页、详情与操作

1. 点击页面标题下方的分页，切换页面内的视图。切换分页不会切换页面。
2. 在「连接」「分流」或「DNS」中选中一行，打开详情。窗口宽度不小于 1200 px 时，详情显示在列表旁的面板中；窗口较窄时以抽屉显示。
3. 使用面板中唯一的主要按钮执行主要任务。连接详情的主要按钮是「新建规则」。
4. 点击「更多操作」（竖排三点按钮）查看其他命令。连接详情中包括「查看命中的规则」「查看流程」「追踪此连接」和「关闭连接」；破坏性操作排在最后。
5. 点击「关闭」或按 `Esc` 关闭面板。

<a name="commit-verbs"></a>

## 暂存、应用或保存

- 「暂存」只出现在「新建规则」对话框中，且是其中突出显示的按钮。它把规则加入暂存列表，但不写入。之后可通过顶部栏的「应用（N）」或「规则」页的「应用暂存的规则」写入；详见[暂存列表](routing.md#held-rules)。
- 「应用」立即把修改写入后端。在「新建规则」中，「应用」会立即写入这条规则并重载 honk。「配置」页用「应用」写入编辑后的来源；「设置」页的「后端选项」卡片用「应用」提交运行时修改，这些修改不写入配置文件。详见[编辑来源](config-and-settings.md#edit-source)和[后端选项](config-and-settings.md#runtime-options)。
- 「保存」把连接方案存储在当前浏览器中。保存后页面会重新加载以应用该连接方案；详见[设置](config-and-settings.md#settings-page)。

<a name="confirm"></a>

## 确认修改已生效

1. 查看写入后的提示消息。写入规则后会显示「新规则已生效」「规则更改已生效」，或在使用「应用（N）」后显示「N 条规则已生效」。
2. 查看提示消息中的说明：「现有连接保持当前路由，重新连接后才应用更改。」
3. 如需检查新路由，打开「连接」，查看修改后新建立的连接。

写入失败时，提示消息会显示原因，未写入的暂存规则仍保留在暂存列表中。配置文件为只读时，请参阅[疑难排解](troubleshooting.md#read-only)。

<a name="phone"></a>

## 在手机上导航

窗口宽度小于 1024 px 时，侧边栏由底部导航栏和页面导航条取代。

1. 在底部导航栏中选择「活动」「观测」「路由」或「设置」。每个分区会打开本次浏览器会话中在该分区最近访问的页面；尚未访问时打开该分区的第一个页面。
2. 在内容上方的页面导航条中选择页面。页面无法全部显示时，横向滑动导航条；当前页面始终保持可见。
3. 点击顶部栏的「更多选项」（竖排三点按钮），可使用「语言」「主题」「配色」和「字标」菜单，以及「重载 honk」和「后端」。「后端」会打开与侧边栏后端指示器相同的弹出框。
4. 搜索按钮、「刷新」和「应用（N）」仍直接显示在顶部栏中，不收入菜单。
5. 在页面工具栏中，第一个操作保留为按钮，其余操作收入「更多操作」。

安装 honk 与 doona 请参阅[安装指南](install.md)；配置文件请参阅[配置](configuration.md#config)。
