# 界面导览

本页说明登录 doona 后各项功能的位置：四个导航分区、顶部栏，以及页面内的标签页、详情面板与操作菜单。本页还说明暂存、应用与保存的区别，如何确认修改已生效，以及手机上的布局变化。

<a name="navigation"></a>

## 查找页面

![活动页，侧边栏按四个分区列出全部页面](../screenshots/zh-CN/activity-light.webp)

| 分区 | 页面                               |
| ---- | ---------------------------------- |
| 活动 | 「活动」「系统状态」               |
| 观测 | 「连接」「分流」「DNS」「日志」「事件」 |
| 路由 | 「策略」「节点」「规则」           |
| 设置 | 「配置」「设置」                   |

只有后端提供时，才显示对应的标签页与卡片。后端不提供的页面仍保留在导航中，打开后显示「此后端不提供该页面」；详见[功能所需条件](features.md#still-missing)。

按 `?` 打开「键盘快捷键」。先按 `g`，再于 800 毫秒内按下页面字母，即可打开对应页面，例如 `g` `r` 打开「规则」。

<a name="top-bar"></a>

## 使用顶部栏

1. 点击侧边栏底部的后端指示器。弹出框会显示引擎及版本、连接状态（例如「已连接」或「需要登录」）、API、「后端网址」和「配置方案」。点击「编辑后端」可打开「设置」页的「后端」卡片，点击「关于 doona」可查看版本信息。
2. 点击搜索框，或按 `Ctrl K`（macOS 上按 `⌘K`）。搜索也涵盖设置字段与动作、持久化 `global` 设置、配置区段与功能入口。
3. 存在暂存规则时，顶部栏会出现带勾选图标和规则数量的按钮，名称为「应用 N 条规则」。规则写入多个文件时，名称也包含「将写入 F 个文件」。点击后会写入全部暂存规则；详见[暂存列表](routing.md#held-rules)。
4. 点击「重载 honk」，并在「重载 honk？」对话框中确认。honk 会重新读取配置文件并重载，暂存的规则不会写入。只有后端支持重载时才显示此按钮。
5. 点击「刷新」或按 `r`，从后端重新读取页面上的全部数据。完成后显示提示消息「数据已刷新。」。刷新不写入任何内容，也不重载 honk。
6. 点击主题按钮切换浅色与深色。主题跟随系统时，点击后切换为相反的配色方案；再次点击恢复为「跟随系统」。旁边是「语言」和「配色」菜单；「字标」选项位于「配色」菜单中。

暂存规则的应用按钮和「重载 honk」不会同时执行：其中一个执行时，另一个不可用。

![搜索 palette，再打开并聚焦外观控件](../screenshots/zh-CN/search-settings.webp)

搜索 `palette`，选择设置结果即可打开并聚焦「外观」控件。选择结果只会导航到控件，不会执行更新、导入或其他动作。

<a name="panels"></a>

## 使用标签页、详情与操作

1. 点击页面标题下方的标签页，切换页面内的视图。切换标签页不会切换页面。
2. 在「连接」「分流」或「DNS」中选中一行，打开详情。窗口宽度不小于 1200 px 时，详情显示在列表旁的面板中；窗口较窄时以抽屉显示。
3. 在「连接」与「分流」中，点击行内的新建规则图标，打开规则对话框。图标禁用时，工具提示说明原因。连接详情面板在可用时也提供「新建规则」。分流详情面板没有新建规则操作。
4. 点击「更多操作」（竖排三点按钮）查看其他命令。连接详情中包括「查看命中的规则」「查看流程」「追踪此连接」和「关闭连接」；破坏性操作排在最后。
5. 点击「关闭」或按 `Esc` 关闭面板。

可搜索的选择器保持搜索框可见，只有选项列表滚动。

<a name="commit-verbs"></a>

## 暂存、应用或保存

![Hold、Apply、Save 与 Done 的写入范围](../images/write-scope.svg)

Hold 将观测规则保留在当前浏览器会话中，重新加载页面即丢弃。Apply 可立即处理或从[暂存列表](routing.md#held-rules)处理，逐个目标文件校验、写入并重载；部分失败时未写入的规则继续暂存，现有连接重新连接后才采用新路由。

运行时 Apply 只修改 honk 的运行值，不写入文件。后端配置方案的 Save 保存在浏览器中并重新加载页面；小工具 Save 与仪表盘 Done 只保存浏览器布局。

## 浮动小工具

![「面板选项 > 编辑小工具」打开的编辑器：小工具库、带宽度把手的实时预览与设置](../screenshots/zh-CN/widgets-editor.webp)

预览读取实时数据。「保存」只把布局保存在当前浏览器中。

![编辑器中选中「实时速率」，显示尺寸与显示方式选项](../screenshots/zh-CN/widgets-speed-settings.webp)

「面板选项 > 合并上传与下载图表」默认开启；关闭后分为两张图表。

![浮动面板未固定且展开、切换页面后收合、固定后在其他页面保持原状、嵌入侧边栏](../screenshots/zh-CN/widgets-states.webp)

面板初始为固定且展开。未固定的面板在切换页面时收合。「收至边缘」只对浮动且未固定的面板生效。

<a name="confirm"></a>

## 确认修改已生效

1. 查看写入后的提示消息。写入规则后会显示「新规则已生效」「规则更改已生效」，或在应用暂存规则后显示「N 条规则已生效」。
2. 查看提示消息中的说明：「现有连接保持当前路由，重新连接后才应用更改。」
3. 如需检查新路由，打开「连接」，查看修改后新建立的连接。

写入失败时，提示消息会显示原因，未写入的暂存规则仍保留。「复制错误」可从失败或结果未知的提示中复制诊断信息。「设置 > 关于」的「复制最近错误」复制内存中最近 20 条错误，不含密钥与请求体。配置文件为只读时，请参阅[故障排查](troubleshooting.md#read-only)。

<a name="phone"></a>

## 在手机上导航

![手机布局：页面导航栏与底部导航栏、「更多选项」菜单及其「配色」子菜单](../screenshots/zh-CN/phone.webp)

窗口宽度小于 1024 px 时，底部导航栏与页面导航栏取代侧边栏。每个分区重新打开本次浏览器会话中最近访问的页面。搜索、「刷新」与暂存规则的应用按钮保留在顶栏中，其余顶栏控件收入「更多选项」；页面工具栏只保留第一个操作为按钮。

安装 honk 与 doona 请参阅[安装指南](install.md)；配置文件请参阅[配置](configuration.md#config)。
