# doona lite 常见操作

使用 doona lite 导入资源并编辑 honk 配置。请先[连接后端](lite-connect.md)。编辑须满足以下全部条件：

- honk 允许写入配置。
- honk 支持操作状态查询与完整配置验证。
- 主配置可写，且 honk 返回完整内容及与其一致的内容哈希。

也可选择**试用演示**练习；重新加载页面后，修改即重置。

<a name="lite-task-import"></a>

## 从分享链接导入节点

1. 打开**节点**，选择**添加节点**。
2. 在**粘贴链接**标签页的**分享链接**中，每行粘贴一个链接。界面会自动识别链接。
3. 检查识别出的协议与地址，并修正无效行。
4. 导入多个节点时，选择**添加 N 个节点**；导入单个节点时，选择**添加**。此操作会直接写入并应用节点，随后在列表中显示。

分享链接导入还要求 honk 支持语法验证。

<a name="lite-task-subscription"></a>

## 添加订阅

1. 打开**订阅**，选择**添加订阅**。
2. 输入**订阅链接**。可填写**名称（可选）**，或留空以使用建议名称。
3. 选择**保存**。订阅以草稿行显示，此时尚未保存至 honk。
4. 选择**查看并应用**，检查修改，然后选择**应用**。
5. 等待“配置已保存并应用。”通知，确认订阅已应用。

编辑与删除订阅采用相同的草稿及确认流程。此处无法重命名已有订阅。

<a name="lite-task-group"></a>

## 创建组并选择成员

1. 打开**策略组**，选择**创建组**。
2. 输入**名称**，选择**策略**，例如**手动选择**，然后选择**创建**。
3. 在**编辑组**中，从**可用节点和订阅**找到节点，选择其**添加**按钮。节点会出现在**已加入**中。
4. 选择**查看并应用**，检查组及成员，然后选择**应用**。

<a name="lite-task-rule"></a>

## 添加路由规则

1. 打开**路由**，选择**添加规则**。
2. 要匹配域名，保留**域名及子域名**，在**值**中输入 `example.com`，按 Enter。
3. 在**走向**中选择组，并选择**位置**，然后选择**添加**。
4. 选择**查看并应用**，检查规则，然后选择**应用**。

**用模板重建规则**对话框可替换草稿中的路由规则。保存前请检查替换列表；此操作并非仅追加一条规则。

<a name="lite-task-dns"></a>

## 修改 DNS 上游

1. 打开 **DNS**，选择**添加 DNS 服务器**。
2. 在**服务商**中保留**自定义**。输入唯一的**名称**和**服务器地址**，例如 `tls://1.1.1.1:853`，然后选择**添加**。
3. 打开该服务器的**操作**菜单，选择**设为默认**，让其他域名使用该服务器。
4. 选择**查看并应用**，检查服务器和规则的修改，然后选择**应用**。

<a name="lite-task-setting"></a>

## 修改全局设置

1. 打开**设置**，选择**嗅探**。
2. 将**嗅探超时**设为 `200`，将其**时长单位**设为 `ms`。
3. 选择**查看并应用**，检查修改，然后选择**应用**。

需要重启的设置显示为只读值，可通过**复制**按钮复制配置行。请按对话框内的说明，在 honk 所在主机修改文件的 `global` 区段，再重启 honk；复制操作不会执行重启命令。

<a name="lite-task-share"></a>

## 通过链接或二维码分享节点

1. 打开**节点**，找到手动添加的节点。
2. 打开节点的**操作**菜单，选择**分享**，打开链接和二维码。
3. 选择**复制链接**，或扫描二维码。如果无法复制，请选中并复制显示的链接。

订阅节点不提供分享链接。链接过长时可能不显示二维码，请改为复制链接。分享链接包含连接凭据。
