# 观测流量

用「活动」与「系统状态」查看引擎健康，用「连接」「分流」与「DNS」检查流量。「日志」与「事件」显示后端数据流。

<a name="activity"></a>

## 活动

doona 默认打开「活动」；在[外观](config-and-settings.md#settings-page)的「启动时打开」中可改为其他页面。

![活动页默认布局：出站控件与状态，下方为下载、上传、连接、延迟与 CPU](../screenshots/zh-CN/activity-light.webp)

状态卡片在有功能关闭时显示关闭的数量，否则显示「查看详情」；两者都打开「系统状态」。

### 开始使用

设置尚未完成且后端提供所需数据时，「开始使用」显示三个步骤：

1. 添加订阅或节点。「添加订阅」会在[节点](routing.md#nodes)直接打开对话框；添加订阅或代理节点后，此步骤完成。
2. 选择路由规则。「选择规则」打开「规则」。应用模板或自定义路由后，此步骤完成。
3. 检查连接。「检查连接」打开[策略](routing.md#policies)。测试当前节点延迟；组所选节点获得成功的延迟测试结果后，此步骤完成。

步骤自动更新。全部完成或点击关闭图标后，卡片隐藏。doona 在此浏览器中保存此状态。

### 出站模式

1. 在「出站模式」卡片选择「规则」、「直连」或「全局」。
2. 选择「全局」时，在「全局出站」卡片选择出站。选定出站前，「应用」按钮不可用，卡片显示「全局模式须指定出站」。选择出站也会同时选中「全局」。
3. 点击已修改的模式或出站旁的「应用」。doona 将修改写入主配置并重载，完成后提示新模式。只选择模式而不点击「应用」，不会更改设置。

卡片显示「只读」时，doona 无法写入主配置。点击「只读」可查看原因，处理方法见[只读的配置文件](troubleshooting.md#read-only)。卡片显示「此后端不提供」时，表示后端没有提供此卡片可编辑的配置。

### 卡片

「下载」与「上传」打开「连接 > 流量」，「活动连接」打开连接列表，「延迟」在[节点](routing.md#nodes)中打开对应节点，「CPU」打开「系统状态」。

- 「延迟」跟随一个策略组选中的节点。「自动」跟随活动连接最多的组；该选择保存在当前浏览器中，只影响这张卡片。
- CPU 与延迟在有两个样本后绘制趋势图。探测失败处留空，切换组后重新开始。「设置 > 外观 > 活动卡片显示趋势图」可关闭趋势图。
- 「设备／域名排行」只统计后端返回的连接样本。
- 运行时数据读取失败时，最后的数值以灰色显示，直到再次读取成功。
- eBPF 后端只报告用户空间流量时，「流量」标题旁的说明指出：内核直接转发的直连连接不计入。「连接 > 流量」的标题旁也显示相同说明。
- 「通知与问题」将相同提示合并为一行并显示重复次数，徽标统计不同提示的数量。数据流就绪事件只保留在「事件」页，不再出现在此卡片。没有对应记录的流程缺口显示为「流程记录丢失：记录设置变更」。

![「内存」显示为带走势线的数值卡，另有一张全宽「内存」卡片列出峰值与平均值](../screenshots/zh-CN/widgets-memory-wide.webp)

![「活动」页的「通知与问题」卡片，以及蓝底白字的信息提示](../screenshots/zh-CN/notices-light.webp)

### 编辑仪表盘

![「编辑仪表盘」中下载卡片宽度为 1/3、高度为「高」，显示把手与该行剩余空间](../screenshots/zh-CN/dashboard-settings.webp)

各卡片可用的尺寸不同；调整一张卡片不会改变相邻卡片。「移除」后可「撤销」；「完成」把布局保存在当前浏览器中，「取消」放弃修改。

![小工具库，显示尺寸预览与已放置数量](../screenshots/zh-CN/dashboard-gallery.webp)

每个小工具最多放置三次。

![「实时速率」卡片使用面积图，下载与上传共用一张图表](../screenshots/zh-CN/dashboard-speed-area.webp)

默认仪表盘把下载与上传分为两张卡片。

小工具库提供「订阅额度」「出站失败」「节点可用性」与「DNS 延迟」。内存可使用图表或「迷你折线图」数值卡片。宽卡片在图表旁显示峰值与平均值，详见[小工具](features.md#widgets)。

<a name="overview"></a>

## 系统状态

从导航栏打开「系统状态」，或在「活动」页点击「查看详情」或「CPU 使用率」数值。页首显示引擎状态、「配置版本」、「运行时间」、「CPU 使用率」与「上次重载」。「配置版本」标识当前生效的配置修订，不是 `generation` 编号。

1. 「引擎」显示引擎版本、「API」、「构建」、「实例」、「启动时间」与「配置生效」。标签显示后端的能力等级：「基本」或「完整可观测」。
2. 「流量计数」显示「TCP 连接」、「UDP 连接」、「连接总数」、「上传」、「下载」与「速率统计间隔」。下方一行显示计数起始时间，以及计数涵盖「全部流量」或「可见流量」。
3. 「内存」显示后端报告的「常驻内存」、cgroup 数值与「OOM 次数」。仪表标有名称，比较 cgroup 用量与非零上限；上限为零或缺失时不显示仪表。
4. 「数据路径」显示内核中 eBPF 程序、挂钩和映射表的检查结果，以及「挂载点」表格。数据路径错误与运行时降级以警告显示在卡片下方。
5. 「后端能力」列出后端提供的功能。点击功能可前往使用该功能的页面。
6. 只有部分功能未开启时才会显示「未开启的功能」。每行列出原因与受影响的功能。「开启方法」显示须添加的设置；「可能原因」说明原因；其他行链接到「设置」页的「临时运行时覆盖」或「地理数据」，或链接到本指南。
7. 点击「导出状态 JSON」下载后端报告的状态。「重载」、「暂停」与「恢复」只在后端允许时显示，每次操作的结果以提示消息显示。

状态卡片加载时用骨架屏保留空间，加载提示显示进度圆环。辅助技术可读取仪表的名称与数值文字。

![「系统状态」页，「内存」卡片中显示 cgroup 内存用量条](../screenshots/zh-CN/system-status-meters.webp)

<a name="connections"></a>

## 连接

「连接」默认打开「流量」标签页；筛选列表或选中连接的链接会打开「连接」标签页。

![「流量」标签页：每条连接的上传与下载，以及节点延迟](../screenshots/zh-CN/connections-traffic.webp)

点击一个点即可打开该连接。节点延迟不限于 TCP 探测。

![「连接」标签页，显示筛选、分组与连接列表](../screenshots/zh-CN/connections-list.webp)

- 「筛选」也匹配出站、链路与规则。「导出 CSV」下载筛选后的列表。
- 出现截断提示、「部分连接可见」或「无连接可见」时，列表为空并不代表设备没有连接。
- 行内的新建规则图标打开[规则对话框](routing.md#add-rule)。图标停用表示该连接没有可匹配的域名或 IP 地址。
- 「更多操作」提供「查看命中的规则」「编辑命中规则的出站设置」「查看流程」「追踪此连接」（见[追踪](routing.md#trace)）「仅显示此设备」与「关闭连接」。只由 eBPF 观测到的连接由内核转发，因此「关闭连接」不可用。
- 只用设备与网络筛选时，「全部关闭」关闭所有匹配的连接，包括对话框打开后新建立的连接。使用其他筛选或列表被截断时，逐条关闭列出的连接。内核直连的连接会被跳过。

<a name="flows"></a>

## 分流

「分流」以总览图与记录显示 honk 如何为已记录的流程选择路由。

![分流总览：先选规则再选节点，固定其路径](../screenshots/zh-CN/routing.webp)

「查看此路径的 N 条流程」打开按该路径筛选的记录；「清除路径筛选」取消固定。

在记录中选中一个流程可查看其追踪步骤。追踪不完整时显示「不完整原因」。连接仍存在时，「查看连接」会打开它。新建规则图标只在记录行中提供。「记录设置」打开[临时运行时覆盖](config-and-settings.md#runtime-options)。

<a name="dns"></a>

## DNS

「DNS」包含「统计」「解析记录」「缓存」与「查询」标签页，实际显示哪些取决于后端支持。

![DNS 统计：延迟、结果、缓存与热门查询](../screenshots/zh-CN/dns.webp)

- 「统计」只汇总解析记录的最新一页。点击热门查询可打开按其筛选的「解析记录」。
- 在「解析记录」中，行内的新建规则图标为该域名打开 DNS request 规则；后端不提供 DNS 规则时改为路由规则。选择「域名后缀」可包含子域名。「导出 CSV」只包含已加载的记录。
- 缓存只保存在内存中，重启后清空。「显示已到期」会一并列出已过期的条目。仪表比较用量与非零容量，容量为零时不显示。「删除匹配项」删除所有匹配模式的条目，而不只是当前页面，确认前显示匹配数量。「清除全部缓存」无法撤销。
- 「查询」的结果仅用于诊断，不会出现在「解析记录」中。「上游」提供「自动」（遵循 `dns.routing`）或已命名的 `dns.upstream`。「略过缓存」默认关闭。

![「缓存」开启「显示已到期」，列出一条已到期记录；右侧为「统计」中的缓存用量条](../screenshots/zh-CN/dns-cache-expired.webp)

<a name="logs"></a>

## 日志

「日志」显示引擎的实时日志。

![日志页，显示按级别统计的活动图表与「级别」「模块」筛选](../screenshots/zh-CN/logs.webp)

- 低于引擎记录级别的级别会被标出；在[临时运行时覆盖](config-and-settings.md#runtime-options)的「记录设置」中降低引擎级别。
- 「暂停」期间只保留最新的记录。「清空」只清空本页面；「导出」下载已接收的记录。
- 重新连接后会重放保留的记录；无法重放时，列表标出缺口。
- 显示「配置禁止日志记录」时，需要修改 honk 的[配置](configuration.md#config)；显示「请先在设置页开启日志记录」时，在「记录设置」中开启即可。

<a name="events"></a>

## 事件

「事件」显示后端的事件流，新事件在前。

1. 「种类」默认为「排除运行状态更新」。可改选「所有种类」，或后端提供的单一种类。
2. 列表的列为「时间」、「种类」与「摘要」。工具栏显示连接状态、保留的事件数，以及可续传时的「可从上次位置续传」。
3. 点击事件可查看完整摘要。「配置生效」事件提供「查看配置」链接。「流程记录丢失」事件提供「查看流程记录」与「记录设置」链接。
4. 点击「导出 JSON」下载当前显示的事件。

页面重新连接后会补回仍保留的事件。若续传位置已失效，列表会以一行标明丢失的事件。
